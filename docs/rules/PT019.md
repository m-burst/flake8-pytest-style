# PT019

`fixture {name} without value is injected as parameter, use @pytest.mark.usefixtures instead`

## Examples

Bad code:

```python
def test_foo(_patch_something):
    ...
```

Good code:
```python
import pytest

@pytest.mark.usefixtures('_patch_something')
def test_foo():
    ...
```

```python
import pytest

@pytest.mark.parametrize('_value', [1, 2, 3])
def test_foo(_value):
    ...
```

Argument names declared in `@pytest.mark.parametrize` on the test function
are not reported, because they receive values from parametrization rather than
unused fixtures. Only names that can be read statically from a string, CSV,
tuple, or list on that decorator are recognized. Names coming from variables,
class- or module-level marks, or other dynamic expressions are not exempted.

## Rationale

* to avoid unused parameters in test functions
