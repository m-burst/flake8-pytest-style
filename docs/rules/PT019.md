# PT019

`fixture {name} without value is injected as parameter, use @pytest.mark.usefixtures instead`

## Examples

Bad code:

```python
def test_foo(_patch_something):
    ...
```

Good code:
```python
import pytest

@pytest.mark.usefixtures('_patch_something')
def test_foo():
    ...
```

Arguments injected by `unittest.mock.patch` and `patch.object` decorators,
including decorators applied to the test class, may have leading underscores:

```python
from unittest.mock import patch

@patch('package.client')
def test_foo(_mock_client):
    ...
```

The rule recognizes the names `patch`, `mock.patch`, and `unittest.mock.patch`
and their `.object` variants when their arguments are specified explicitly.

## Rationale

* to avoid unused parameters in test functions
